# Delegation
*Teamwork makes the workshop work*

To make a workshop truly successful, you're going to want to build a team. A single person can do it all, but that can be a lot of work.

## Getting Started
When you are first getting started planning your workshop, the three key decisions from which other things (e.g. content, environment) flow are:
* Venue
* Date
* Speaker/Subject

It's possible to change these as more information is obtained, but do so deliberately, not casually.

## Event Organization
Leading up to the workshop, there are many areas which will benefit from attention and organization. These can be done by the organizer or delegated to a team member.

* Content
    * Creating the content if new
    * Validate the content if reusing
    * Test the content, especially if new, but also for timing
* Marketing
* “Day-of” Logistics
    * Food
    * A/V
    * Security

## Day-Of Event Support
On the day of the event, there's usually a higher level of support than leading up to it.  Helping on the day-of is usually the least effort, however these folks are the least invested so they are at the highest risk of not showing up.  As such, plan for more help than you think you need.

The type of support required will vary based on the workshop, however there are both technical and non-technical jobs:
* Greeter
* Venue liaison
* Workshop technical support
* Food (set up/clean up)
